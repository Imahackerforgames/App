Put the salon photos in this folder.

Instagram blocks direct image downloads, so they couldn't be fetched
automatically. To add them:

  1. Open each post on Instagram and save the photo.
  2. Save the files here as 01.jpg, 02.jpg, 03.jpg ... 08.jpg
     (or any names you like).
  3. If you use different names, update the "gallery" list in ../../data.js
     so each "image" value matches your file name.

Until a file exists, that card shows a styled placeholder that still links
to the original Instagram post — the site never shows a broken image.

Tip: square or portrait photos look best. The cards crop to 4:5.
