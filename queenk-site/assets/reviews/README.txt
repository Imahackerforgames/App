CLIENT PHOTOS ("vouch proof")
============================

The four customer review photos from Queenie's flyer go here.

They arrived as a screenshot, so the individual image files could not be
saved automatically. To add them:

  1. Save each of the four review photos as its own image file.
  2. Put them in this folder as:  01.jpg  02.jpg  03.jpg  04.jpg
  3. That's it — the polaroid frames on the site pick them up.

If you use different file names, update the "clientPhotos" list in
../../data.js so each "image" value matches.

Until a file exists, that frame shows a styled placeholder instead, so the
site never displays a broken image.

Tip: portrait photos look best. The frames crop to 3:4.
